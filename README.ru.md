## 📖 О проекте

Telegram Bot — Restaurant Search — это Telegram-бот, разработанный на Python для поиска ресторанов по типу кухни и предпочтениям пользователя.

Бот позволяет искать рестораны, получать информацию о заведениях и просматривать историю предыдущих поисковых запросов.

Приложение создано в качестве учебного дипломного проекта по Python и демонстрирует практические навыки интеграции с Telegram Bot API, обработки команд, работы с базами данных и взаимодействия с пользователями.

## ✨ Возможности

- 🔍 Поиск ресторанов по типу кухни или ключевым словам
- 🍣 Поиск суши, пиццы и других категорий еды
- 🏠 Отображение названия, адреса и доступных фотографий ресторана
- 📜 Сохранение истории поисковых запросов
- 🗂️ Просмотр предыдущих запросов
- 🤖 Обработка команд Telegram
- 👋 Приветственное сообщение и справочная информация

## 📖 Команды бота

| Команда | Описание |
|---|---|
| `/start` | Запуск бота и приветствие |
| `/help` | Список доступных команд |
| `/find <cuisine>` | Поиск ресторанов по типу кухни |
| `/history` | Просмотр истории поисковых запросов |

### Примеры использования

```text
/start
/help
/find sushi
/find pizza
/history
```

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/PhilipTataroii/Telegram-Bot-Search-Restaurant.git
cd Telegram-Bot-Search-Restaurant
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

Активация в Windows:

```powershell
.\.venv\Scripts\Activate.ps1
```

В Linux/macOS:

```bash
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка токена Telegram

Открой файл:

`Token_and_Database/config.py`

Укажи токен своего Telegram-бота:

```python
BOT_TOKEN = "your_bot_token"
```

Получить токен можно через официального бота @BotFather в Telegram.

**Безопасность:** никогда не публикуй настоящий токен в GitHub. Для реального использования рекомендуется хранить его в переменных окружения или локальном конфигурационном файле, исключённом из Git.

### 5. Запуск бота

```bash
python Start_Bot/bot.py
```

## 🔎 Проверка работы

После запуска открой бота в Telegram и выполни команды:

| Команда | Ожидаемый результат |
|---|---|
| `/start` | Приветственное сообщение |
| `/help` | Список команд |
| `/find sushi` | Поиск суши-ресторанов |
| `/find pizza` | Поиск пиццерий |
| `/history` | История поисковых запросов |

Для работы бота программа должна быть запущена на компьютере или сервере.
