# -Telegram-Bot-Search-Restaurant
🍽️ This bot helps users find restaurants by cuisine type (e.g., 🍣 sushi, 🍕 pizza) and saves the search history.   🎓 The project was created as a Python diploma work and demonstrates:   - 🔗 Integration with Telegram API   - 🗄️ SQLite database usage via ORM Peewee   - ⚙️ Command handling and user interaction
