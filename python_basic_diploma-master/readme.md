# Ресторанный Telegram‑бот 🍣🍕

## 📌 Описание
Этот бот помогает находить рестораны по типу кухни (например, суши, пицца) и сохраняет историю запросов пользователя.  
Проект создан как дипломная работа по Python и демонстрирует работу с Telegram API, базой данных SQLite через ORM Peewee, а также обработку команд.

---

## ✨ Возможности
- Поиск ресторанов по ключевым словам (например: `/find суши`).
- Отображение названия, адреса и фотографии ресторана.
- Сохранение истории запросов пользователя.
- Просмотр последних запросов через команду `/history`.
- Справка по всем командам через `/help`.
- Приветственное сообщение и описание возможностей через `/start`.

---

## 📖 Команды
- `/start` — приветствие и краткое описание функций бота.  
- `/help` — список всех доступных команд.  
- `/find <кухня>` — поиск ресторана по типу кухни (например: `/find пицца`).  
- `/history` — просмотр последних запросов пользователя.

## 🚀 Установка и запуск

### 1. Клонирование проекта
```bash
git clone https://gitlab.skillbox.ru/filip_tataroi/python_basic_diploma.git
cd python_basic_diploma
```
### 2. Активация виртуального окружения
```bash
В проекте уже есть папка .venv.
--Активируйте её--
На системе Windows:
.venv\Scripts\activate
На системе Linux/Mac:
source .venv/bin/activate
```
### 3. Установка зависимостей
```bash
Все необходимые библиотеки указаны в requirements.txt.
--Установите их командой--
pip install -r requirements.txt

--В проекте используются--
Aiogram — работа с Telegram API
Peewee ORM — база данных SQLite
Requests — HTTP‑запросы
```
### 4.Настройка токена
```bash
В файле Token_and_Database/config.py укажите свой токен Telegram‑бота:

BOT_TOKEN = "ваш_токен_бота"
```
### 5.Запуск бота
```bash
python Start_Bot/bot.py
```

## 🔎 Как проверить работу
1. Запустите бота.

2. В Telegram отправьте команду /start — бот должен ответить приветствием.

3. Введите /help — бот покажет список команд.

# Попробуйте поиск:
/find суши - бот вернёт ресторан.
Введите /history — бот покажет последние запросы.

## 📂 Структура проекта
1. Handlers_Bot/ — обработчики команд (start.py, help.py, find.py, history.py).

2. Start_Bot/bot.py — главный файл запуска бота.

3. Token_and_Database/config.py — настройки: токен, база данных, формат даты.

4. requirements.txt — список зависимостей.

5. readme.md — инструкция по установке и запуску.

6. .venv/ — виртуальное окружение.

## 🛠 Технологии
1. Python — язык разработки

2. Aiogram — библиотека для работы с Telegram API

3. Peewee ORM — работа с базой данных SQLite

4. SQLite — хранение данных о ресторанах и истории запросов
